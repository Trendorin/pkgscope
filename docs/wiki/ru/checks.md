# Форматы и проверки

## Что читается

| | |
|---|---|
| Debian | `.deb`, `.ipk` (OpenWrt) |
| RPM | `.rpm`, свой разборщик заголовка с проверкой границ |
| Arch | `.pkg.tar.zst`, `.xz`, `.gz` с `.INSTALL` и `.MTREE` |
| Другие | Alpine `.apk`, Void `.xbps`, Slackware `.txz` и `.tgz` с `doinst.sh` |
| Образы | AppImage (тип 1 и 2), Snap, SquashFS |
| Отдельные файлы | ELF-программы и библиотеки, модули ядра, скрипты shell, Python и Perl, установщики makeself |

## Что показывается

| | |
|---|---|
| Дерево файлов | путь установки, права, владелец, размер, SHA-256; setuid, доступные всем на запись, скрытые файлы и устройства выделены |
| Скрипты | preinst и postinst, `%pre` и `%post`, `.INSTALL`, `doinst.sh` со строками, сработавшими на правила |
| ELF | PIE, NX, RELRO, защита стека, FORTIFY, RPATH и RUNPATH, заметные импорты, упаковщики, библиотеки, подменяющие libc (руткиты через `LD_PRELOAD`) |
| Целостность | каждый файл сверяется с контрольными суммами самого пакета (`md5sums`, дайджесты RPM, `.MTREE`) |
| Правила | больше 100: скачать-и-запустить, обратные шеллы, закрепление через cron, systemd, PAM и udev, кража учётных данных, майнеры, заметание следов, разрушительные команды |
| Индикаторы | URL, IP, домены и адреса `.onion`; ссылки на документацию отфильтрованы |

## Важность и риск

У каждой находки есть важность (Critical, High, Medium, Low или Info), объяснение и
доказательство: файл и строка или событие во время работы. Оценка риска 0–100 и вердикт сверху
подводят итог; на вкладке Overview — находки от Medium и выше.

Чистый результат значит, что ничего очевидного не нашлось. Это не доказывает, что файл безопасен.
