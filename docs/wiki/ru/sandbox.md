# Песочница

**Inspect & Trace** (или `pkgscope-cli --trace`) запускает установщик и записывает, что он делает.

## Что запускается

Для пакетов повторяется работа менеджера пакетов: dpkg `preinst → unpack → postinst`, rpm
`%pre → unpack → %post`, pacman `pre_install → post_install`. AppImage, ELF-файлы и скрипты
запускаются напрямую, с дополнительными аргументами из настроек.

## Как изолируется

`pkgscope-sandbox` — маленький помощник без Qt и без setuid. От имени фиктивного root он
настраивает:

- пространства имён user, mount, PID, IPC, UTS, cgroup и по умолчанию network;
- copy-on-write overlay поверх `/usr`, `/etc`, `/opt` и `/var`, поэтому на диске ничего не
  меняется;
- урезанный набор capabilities, rlimits и фильтр seccomp, который запрещает загрузку модулей,
  `bpf`, `kexec`, монтирование, новые пространства имён, `io_uring` и другое;
- на Linux 6.12+ — Landlock: нет доступа к абстрактным сокетам хоста (X11, D-Bus) и сигналам
  процессам снаружи.

Разрешение сети или доступа к дисплею в настройках ослабляет эту изоляцию.

## Что вы получаете

Дерево процессов, работу с файлами с чтением чувствительных (и заблокированным), diff файловой
системы, сетевые соединения с хостами DNS, SNI и HTTP и файлы, созданные и запущенные во время
установки. Находки во время работы помечены «runtime».

## Если трассировка не запускается

**Analyze → Check sandbox support** скажет, чего не хватает.

| сообщение или система | что сделать |
|---|---|
| Ubuntu 24.04+ | пакет Debian ставит профиль AppArmor; из исходников — `./install.sh --setup` |
| `overlay … read-only`, нет overlayfs | `sudo modprobe overlay` (пакеты загружают модуль при старте) |
| не найден `strace` | поставьте `strace` |
| AppImage не распаковывается | поставьте `squashfs-tools` |
