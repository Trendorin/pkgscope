# Командная строка

```
pkgscope-cli [параметры] ФАЙЛ
```

| параметр | |
|---|---|
| `--trace` | ещё и запустить файл в песочнице и записать поведение |
| `--allow-network` | пустить запущенную программу в сеть (по умолчанию изолирована) |
| `--timeout СЕК` | секунд на этап песочницы (по умолчанию из настроек) |
| `--keep` | оставить каталог песочницы для ручного изучения |
| `-j, --json ПУТЬ` | отчёт в JSON |
| `--html ПУТЬ` | отчёт в HTML |
| `--md ПУТЬ` | отчёт в Markdown |
| `-q, --quiet` | вывести только строку с вердиктом |
| `--fail-on УРОВЕНЬ` | код выхода 3, если есть находка этого уровня или выше (`low`, `medium`, `high`, `critical`) |

## Коды выхода

| код | значение |
|---|---|
| 0 | готово |
| 1 | файл не удалось разобрать |
| 2 | неверные аргументы |
| 3 | сработал `--fail-on` |

## В CI

```sh
pkgscope-cli --trace --fail-on high --json pkgscope.json ./dist/myapp.deb
```

AppImage запускает ту же командную строку с `--cli`: `./PkgScope-*.AppImage --cli ФАЙЛ`.
